# AI Automation Avanzado

Proyecto integrador desarrollado durante el trayecto de AI Automation Avanzado.

## Módulo 1 — Construcción del Agente Base

Este módulo contiene la primera versión del agente de IA desarrollado en n8n.

### Arquitectura

- Chat Trigger
- AI Agent
- OpenAI Chat Model (GPT-4o)
- Google Sheets como Tool
- Slack para observabilidad

### Configuración

- Agente configurado con System Message modular.
- Límite de iteraciones configurado en 7.
- Google Sheets conectado como herramienta lateral del AI Agent.
- Slack utilizado como canal de notificación y observabilidad.

### Archivo

`checkpoint1_nombre_apellido.json`

El workflow será ampliado progresivamente en los siguientes módulos del proyecto.
